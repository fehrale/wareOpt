# WareOpt

**WareOpt** — веб-приложение для оптимизации размещения товаров в складской системе с учётом частоты обращений к товарам и ограничений хранения.

Проект разрабатывается в рамках выпускной квалификационной работы на тему **«Разработка метода оптимизации размещения товаров в складской системе с учётом частоты обращений и ограничений хранения»**.

## О проекте

С развитием электронной коммерции и ростом объёмов складских операций возрастает необходимость эффективного использования складского пространства и сокращения времени комплектации заказов.

Расположение товаров влияет на расстояние, которое сотрудники проходят при сборке заказов. Размещение востребованных товаров в легкодоступных зонах может сократить перемещения и ускорить складские операции. При этом необходимо учитывать характеристики товаров, вместимость складских зон и ограничения хранения.

WareOpt предназначен для анализа существующего расположения товаров, расчёта оптимизированной схемы размещения и визуального сравнения результатов.

## Цель проекта

Разработать метод оптимизации размещения товаров в складской системе с учётом частоты обращений и ограничений хранения, направленный на **сокращение суммарного расстояния перемещения при комплектации заказов** и повышение эффективности использования складских ресурсов.

## Задачи

1. Проанализировать существующие методы размещения товаров в складских системах, их преимущества, недостатки и возможности применения математической оптимизации.
2. Разработать математическую модель размещения товаров.
3. Разработать алгоритм оптимизации размещения товаров.
4. Реализовать программную систему с визуализацией результатов оптимизации.
5. Проанализировать результаты и определить условия, при которых разработанный метод наиболее эффективен.

## Планируемые возможности

- **Визуализация склада:** отображение схемы склада, стеллажей, зон хранения и текущего расположения товаров.
- **Настройка исходных данных:** задание характеристик товаров, частоты обращений и ограничений размещения.
- **Оптимизация размещения:** автоматический расчёт рекомендуемой схемы расположения товаров.
- **Сравнение схем:** визуальное сопоставление исходного и оптимизированного вариантов.
- **Анализ эффективности:** графики и показатели, позволяющие количественно оценить результаты оптимизации.

> Перечисленные возможности описывают ожидаемый результат проекта и не означают, что все функции уже реализованы.

## Математическая составляющая

Предмет исследования — **математические модели и методы оптимизации размещения товаров** с учётом частоты обращений и ограничений хранения.

Основная задача — подобрать размещение товаров, позволяющее сократить суммарное расстояние перемещений при комплектации заказов, не нарушая ограничений складской системы.

Конкретная математическая постановка задачи и алгоритм оптимизации будут определены в ходе исследования.

## Технологический стек

| Технология | Назначение |
| --- | --- |
| **React JS** | Реализация математической модели и алгоритмов оптимизации размещения товаров (согласно проектному плану) |

## Практическая значимость

Разрабатываемая система ориентирована на небольшие и средние складские предприятия. Она может применяться для анализа текущего размещения товаров и формирования рекомендаций по его улучшению **без полной реорганизации складской инфраструктуры**.

Ожидаемый эффект — сокращение перемещений при комплектации заказов и более эффективное использование доступного складского пространства.

## Ожидаемый результат

Результатом проекта станет программная система, которая демонстрирует применение методов математической оптимизации к задаче складской логистики и позволяет оценить преимущества предложенного метода с помощью **интерактивной схемы склада, сравнения вариантов размещения и графиков эффективности**.
